Character Design v2 -- Box Characters

Paper.io 2 / Crossy Road inspired blocky character system. Live interactive Three.js scenes. Director feedback: keep everything angular. Authored by Jen, 2026-04-29.

Director Feedback Applied

The v1 proposal recommended capsule/sphere bodies. The Director rejected this in favor of a fully box-based aesthetic inspired by Paper.io 2 skins (voxel animals) and Crossy Road characters. All geometry must be BoxGeometry -- no spheres, cylinders, or rounded shapes whatsoever.

This page presents the revised character design system: box-based bodies with expressive flat-surface faces, personality through proportions and color, and the same team differentiation system adapted for angular characters. All visuals below are live Three.js scenes with auto-rotation -- drag to rotate manually.

  • Geometry constraint: BoxGeometry only. No SphereGeometry, CylinderGeometry, or CapsuleGeometry.
  • Reference games: Paper.io 2 skins, Crossy Road, Angry Birds blocky fan art
  • Charm source: Proportions + face expressions on flat surfaces + bold color
  • Camera angle: ~60-degree top-down perspective, ~20 units above ground
  • Max players: 8 simultaneous, each with a distinct color

1. Reference Style Analysis

What makes Paper.io 2 and Crossy Road characters work, and how we adapt it.

Key principles from reference games. Paper.io 2 skins and Crossy Road characters share common traits: oversized heads relative to body, flat-surface facial features, sharp 90-degree edges only, and personality via proportions rather than detail. All geometry is axis-aligned boxes -- curves are approximated by stacking smaller boxes (but we avoid even that for our game-scale characters where simplicity wins).
Why boxes work for this game: At game camera distance (~20 units up), characters are 6-15 pixels on screen. Rounded forms and sharp boxes look identical at that scale. The box aesthetic gives us: (1) cheaper geometry, (2) clearer silhouettes from the top-down angle, (3) a style identity that matches the grid-based territory system. The charm lives in close-up moments -- kill cams, menus, lobby -- where facial expressions and proportions become visible.

2. Box Character Variants

Four body proportion archetypes, all built from BoxGeometry. Each has distinct personality through shape ratios alone.

Four proportion archetypes. (A) Chunky -- wide body, big head, Crossy Road chicken vibe. Default player shape. (B) Tall -- narrow body, smaller head, more vertical. Possible future skin. (C) Squat -- short and wide, big face. Angry Birds "bomb" proportions. (D) Chibi -- huge head, tiny body. Maximum face readability at distance. All use the same BoxGeometry primitives, just different dimensions.

3. Expressive Faces on Flat Surfaces

Eyes, eyebrows, and mouth built as flat BoxGeometry on the front face of the head. No textures needed.

Face expression system. All facial features are flat BoxGeometry quads on the front face of the head box. Eyes are white boxes with black box pupils. Eyebrows are thin dark boxes above eyes. Mouth is a simple flat box. Expressions change by adjusting eyebrow angle, eye shape, and mouth position. At game scale these are invisible, but they sell personality in close-ups and UI.
Implementation approach: Faces can be done two ways: (1) Geometry decals -- flat BoxGeometry quads positioned on the head front face. Simple, no textures needed, but more draw calls. (2) Canvas texture -- draw face onto a canvas, apply as texture to head front face. One material, zero extra geometry. Recommendation: start with geometry decals (current eye system but bigger), migrate to canvas textures if performance matters.

9. Implementation Plan

Prioritized changes to PlayerRenderer.ts -- all using BoxGeometry.

Proportion Rework

Adjust body and head BoxGeometry dimensions for the "chunky" archetype: Body 1.0 x 0.9 x 0.8 (wider, shorter). Head 0.85 x 0.75 x 0.75 (bigger relative to body). Head sits directly on body (no gap). ~10 minutes, zero new geometry types.

HIGH PRIORITY

Bigger Face Features

Scale up existing eye boxes from 0.16 to 0.22. Add flat eyebrow rectangles (0.2 x 0.06 x 0.02) above each eye. Optional: small mouth rectangle. All BoxGeometry. ~15 minutes.

HIGH PRIORITY

Diamond Overhead Pointer

BoxGeometry(0.3, 0.3, 0.3) rotated 45 degrees on Y and Z axes to create a diamond shape. White MeshBasicMaterial. Bobbing Y animation. Local player only. ~10 minutes.

HIGH PRIORITY

Shadow Box

Flat BoxGeometry(1.4, 0.02, 1.0) beneath each player at Y=0.01. Black MeshBasicMaterial with opacity 0.12. Grounds the character and provides separation from territory. ~5 minutes.

MEDIUM PRIORITY

Head Color Variation

Make head material slightly lighter than body (lighten by 15%). Creates visual separation between body and head without new geometry. One line in createPlayerMesh(). ~2 minutes.

MEDIUM PRIORITY

Future: Skin System

Paper.io 2 / Crossy Road style unlock skins. Box-based animal variants (pig, chicken, robot, etc.) using additional BoxGeometry parts for ears, snout, etc. Post-launch feature -- proportions + face system first.

STRETCH
Three.js code reference: The current PlayerRenderer.ts already uses BoxGeometry for body (1.2, 1.2, 1.2), head (0.9, 0.9, 0.9), and eyes (0.16, 0.16, 0.16). The proposed changes modify only the dimensions and add a few more BoxGeometry primitives -- no new geometry types needed. Total implementation: ~45 minutes.

10. Reference Code -- createCharacter()

Shared character constructor used on this page and reusable in the game. BoxGeometry only.

function createCharacter(options) { // options: { color, bodyWidth, bodyHeight, bodyDepth, headWidth, headHeight, // headDepth, expression, showPointer, showGroundMarker, showShadow } const group = new THREE.Group(); const c = new THREE.Color(options.color); // Body -- chunky box const bodyGeom = new THREE.BoxGeometry( options.bodyWidth || 1.0, options.bodyHeight || 0.9, options.bodyDepth || 0.8 ); const bodyMat = new THREE.MeshStandardMaterial({ color: c, roughness: 0.5 }); const body = new THREE.Mesh(bodyGeom, bodyMat); group.add(body); // Head -- slightly lighter color const headColor = c.clone().lerp(new THREE.Color(0xffffff), 0.12); const headGeom = new THREE.BoxGeometry( options.headWidth || 0.85, options.headHeight || 0.75, options.headDepth || 0.75 ); const headMat = new THREE.MeshStandardMaterial({ color: headColor, roughness: 0.45 }); const head = new THREE.Mesh(headGeom, headMat); head.position.y = (options.bodyHeight || 0.9) / 2 + (options.headHeight || 0.75) / 2; group.add(head); // Eyes, eyebrows, mouth -- flat boxes on front face of head addFace(group, head, options.expression || 'neutral'); // Diamond pointer (local player) if (options.showPointer) { const ptr = new THREE.Mesh( new THREE.BoxGeometry(0.3, 0.3, 0.3), new THREE.MeshBasicMaterial({ color: 0xffffff }) ); ptr.rotation.set(0, Math.PI / 4, Math.PI / 4); ptr.position.y = head.position.y + (options.headHeight || 0.75) / 2 + 0.5; group.add(ptr); } // Ground marker (flat square) if (options.showGroundMarker) { const marker = new THREE.Mesh( new THREE.BoxGeometry(1.6, 0.02, 1.2), new THREE.MeshBasicMaterial({ color: 0xffffff, transparent: true, opacity: 0.25 }) ); marker.position.y = -(options.bodyHeight || 0.9) / 2 - 0.01; group.add(marker); } // Shadow box beneath if (options.showShadow !== false) { const shadow = new THREE.Mesh( new THREE.BoxGeometry(1.4, 0.02, 1.0), new THREE.MeshBasicMaterial({ color: 0x000000, transparent: true, opacity: 0.12 }) ); shadow.position.y = -(options.bodyHeight || 0.9) / 2 - 0.01; group.add(shadow); } return group; }
