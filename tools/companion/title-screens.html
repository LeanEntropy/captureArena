Land Capture — Title Screen Concepts

Five title-screen design directions for Director review. Each is a full 16:9 mock with the actual name/buttons primitives the game uses today, styled in-direction.

Brief

Game is now branded "Land Capture". The current entry screen is a flat-white card with the heading "Territory War" and two unstyled buttons — the Director wants something dramatic, with action-movie energy and (where possible) a live ThreeJS scene of the island + Vanta-style water already shipped in prototype/main.js.

Each mock below is a working design preview, not a thumbnail. Designs 2 and 4 include live ThreeJS canvases reusing the in-game water shader; the rest are CSS/SVG-only. Buttons are non-functional here — these are direction studies.

Mockup work only. No prototype/ code is touched. tools/companion/ + docs/ only.

4 · Voxel Block Type

"LAND CAPTURE" rendered as 3D voxel blocks — each letter is a stack of cubes. Maximum expression of the BoxGeometry-only ART_ETHOS.

LIVE THREE.JS
FIVE FACTIONS · ONE ISLAND
A GAME BY CIVAX
Background
Sky gradient (peach-dawn → pale teal) matching Theme F's sky. Letters built from BoxGeometry primitives — every glyph is a 5×7 voxel grid extruded to depth 1, lightly rotated, rim-lit. A thin water strip animates at the bottom.
Typography
Procedural — the title IS the geometry. Character coloring rotates through faction palette per frame (each letter is one faction color).
Palette
Theme F sky + faction colors on letters. Cream input + dark borders to match the in-game wooden-stamp HUD.
Layout
Title fills upper 2/3 of frame. Form occupies lower third on the cream form card.
Perf
~0.7 ms/frame — ~330 BoxGeometry instances (5 letters × 5 wide × 7 tall × 2 deep ≈ 350 cubes) shared geometry + InstancedMesh keeps draw calls at 1.
