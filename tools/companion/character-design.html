Character Design Recommendations

Capture Arena -- visual identity system for player characters, team colors, and in-game differentiation. Authored by Jen, 2026-04-29.

Design Brief

Capture Arena is a Paper.io-style territory game viewed from a top-down perspective camera at roughly 60 degrees. Players are small blocky characters moving across a white arena, leaving colored trails and claiming territory. The current design uses a simple box-body + box-head with cube eyes -- functional but personality-free.

This page presents visual recommendations for evolving the character design: stronger silhouettes, better team-color differentiation, and visual personality that reads at game scale. Every mockup below is rendered at approximately the same camera angle as the actual game.

  • Camera angle: ~60-degree top-down perspective, ~20 units above ground
  • Character height: ~2 world units (body 1.2 + head 0.9)
  • Max players: 8 simultaneous, each with a distinct color
  • Key challenge: Characters must read clearly against their own colored territory

2. Character Anatomy

Evolving the blocky base into a more expressive, readable design while staying true to the Paper.io aesthetic.

Current Design: Simple box body + box head. Uniform color everywhere. Eyes are tiny cubes that disappear at game distance. No visual personality beyond color.
Proposed Design: Capsule body with dome top, sphere head with lighter tone, larger expressive sphere eyes. Shadow disc grounds it. Overhead pointer marks "you." Body catches light naturally from directional lighting.
Principle #10 (Simplicity Over Detail): At game camera distance (~20 units up), fine details vanish. The proposed design focuses on three things that do read at distance: (1) body color fill, (2) dome highlight from lighting, (3) shadow disc grounding the character on the plane. Arms, legs, and fine detail are explicitly avoided -- invisible at 20-40px screen size.

3. Same-Color Team Differentiation

When multiple players share a team color, how do we tell them apart? A layered system ensures readability.

Four teammates in the same blue. The local player (leftmost) has: overhead pointer, pill-background name label, and a ground ring. Teammates share the same base mesh -- only the label styling differs. The overhead pointer is the single strongest "that is me" signal.
Tier Technique Priority Reads at Distance? Implementation
1 Overhead pointer (white cone, bobbing) MUST HAVE Yes -- always visible above all geometry ConeGeometry(0.25, 0.4, 4), local player only
2 Name label pill background MUST HAVE Yes -- text always readable CSS change in updateLabel(), local vs other
3 Ground ring / glow NICE TO HAVE Yes -- visible at medium range RingGeometry beneath local player, pulsing opacity
Why not different shapes per teammate? At game scale, shape differences between same-color allies are nearly invisible. The overhead pointer + label styling solves 95% of the "which one is me" problem. Shape/accessory variation is better reserved for a future cosmetic skin system, not for team identification.

7. Implementation Recommendations

Prioritized changes to PlayerRenderer.ts.

Fix Yellow + Deep Orange

Replace washed-out yellow (#FFEB3B) with amber-yellow (#F9A825). Verify orange (#FF9800) vs deep orange (#FF5722) separation at game scale -- if they appear simultaneously, shift one. One-line change in constants.ts.

HIGH PRIORITY

Add Overhead Pointer

White downward-pointing cone above the local player's head. Bobbing animation. The single most impactful change for player self-identification, especially in future team mode. ~15 minutes to implement.

HIGH PRIORITY

Capsule Body Redesign

Replace BoxGeometry body+head with CylinderGeometry+SphereGeometry capsule and sphere head. Rounder forms catch light better, feel warmer. Add shadow disc beneath. ~30 minutes.

HIGH PRIORITY

Label Styling for Local Player

Dark pill background on local player's name label. Other players keep the current light text-shadow style. CSS-only change in updateLabel(). ~10 minutes.

MEDIUM PRIORITY

Bounce Animation

Gentle Y-axis sine bob (amplitude 0.08, ~3Hz). Barely visible at full zoom but adds subliminal life. 3 lines in the update loop.

MEDIUM PRIORITY

Death VFX Improvement

Scatter the actual body parts (head sphere, body cylinder) instead of generic cubes. Invulnerability: glow pulse instead of binary visibility toggle.
